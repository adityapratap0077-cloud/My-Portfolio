## Deploy

**GitHub Pages:**
1. Upload `index.html` + `assets/` folder
2. Settings → Pages → Deploy from branch → main / root → Save
3. Live at `https://yourusername.github.io/portfolio/`

**Vercel:**
1. Import GitHub repo
2. Framework: Other, Build: empty, Output: ./
3. Ensure file at `assets/Aditya_Pratap_Resume_5th_Sem.pdf` (exact case)
4. Deploy — download works
